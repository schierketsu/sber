# Кот-пилот: полёт над Россией

HTML5-игра для трека B «Игры» хакатона «Сбер: Создаем эмоции». Ребёнок ведёт самолётик с котом-пилотом
между препятствиями и пролетает над тремя регионами России — Чувашией, Коми и Бурятией. Каждые 10 очков
открывается открытка о достопримечательности региона, каждые 20 очков меняется регион и фон.

**Учебная задача:** после игры ребёнок знает шесть достопримечательностей трёх регионов России и может сказать,
в каком регионе каждая находится.

## Как играть

- Нажатие на экран — самолётик поднимается.
- Пролетел между препятствиями — 1 очко. Монетка — ещё +2.
- 10, 20, 30, 40, 50, 60 очков — открытка о месте, над которым летишь.
- 20 и 40 очков — перелёт в следующий регион, меняются фон и препятствия: резные столбы с чувашским орнаментом,
  каменные столбы Коми, ледяные глыбы Байкала.
- 60 очков — финиш: экран со всеми открытками и кнопка «Поделиться».

На стартовом экране — кнопка «Полетели!» и мини-комикс, в котором кот-пилот зовёт в путешествие.
Счёт показывается одной цифрой, без максимума. Если самолётик задел препятствие, игра показывает очки
и рекорд, а «Попробовать ещё раз» продолжает полёт с последней открытки.

## Запуск

Игра — набор статических файлов в папке [game/](game/), все пути относительные.

```sh
cd game
python -m http.server 8000
```

Дальше откройте `http://localhost:8000` в браузере или `http://<IP компьютера>:8000` в песочнице
([Android](https://github.com/vveidi/sber-hse-hackathon-2026-android), [iOS](https://github.com/vveidi/sber-hse-hackathon-2026-ios)).
Телефон и компьютер должны быть в одной сети.

## Структура

```
promo/                    обложки и их генератор
game/
  index.html              разметка экранов
  style.css               стили, безопасные зоны экрана
  content/regions.json    контент: регионы, открытки, монетки
  img/cards/*.svg         иллюстрации открыток
  js/bridge.js            события для приложения
  js/sound.js             звуки (Web Audio, без файлов)
  js/content.js           загрузка и проверка контента, встроенная копия на случай ошибки
  js/art.js               графика: фоны, препятствия, самолётик, монетки
  js/game.js              игровой цикл, физика, экраны
```

Код написан на чистом HTML, CSS и JavaScript, без библиотек, фреймворков и сборки. Графика рисуется
на Canvas, шрифты системные. Интерфейс повторяет приложение СберKids: светлый фон, белые карточки,
градиентная главная кнопка, кнопка «закрыть» слева сверху. Вес всей игры — около 120 КБ.

## Контент без релиза

Всё наполнение лежит в `content/regions.json`, и его можно менять без изменения кода:

| Поле | Что задаёт |
|---|---|
| `intro` | две подписи комикса на стартовом экране |
| `pointsPerCard` | через сколько очков открывается открытка (сейчас 10) |
| `coin.chance`, `coin.value` | вероятность монетки и её ценность |
| `regions[]` | регионы по порядку; регион сменяется после его последней открытки |
| `regions[].scene` | фон: `volga`, `ural` или `baikal` |
| `regions[].obstacle` | препятствия: `pillar`, `rock` или `ice` |
| `regions[].speed`, `regions[].gap` | скорость и ширина просвета, то есть сложность региона |
| `regions[].cards[]` | открытки: `title`, `text` (абзацы через пустую строку), `image` |

Картинка открытки — относительный путь или https-ссылка на CDN. Максимум очков считается сам:
число открыток × `pointsPerCard`. Если файл не загрузился или в нём ошибка, игра берёт встроенную копию
из `js/content.js` и продолжает работать.

## Монетки: вероятностная модель

Монетка не лотерея: ребёнок ничего не тратит и ничем не рискует ради неё.

- После каждого препятствия монетка появляется с вероятностью `coin.chance` = 0,35, независимо от прошлых.
- Она висит между двумя препятствиями на высоте между их просветами и даёт `coin.value` = +2 очка.
- За 10 препятствий в среднем появляется 3,5 монетки. Если собирать все, 60 очков набираются примерно
  за 35 препятствий вместо 60.

## События приложения

Игра отправляет `window.postMessage({ type }, "*")` по контракту хакатона:

| Событие | Когда |
|---|---|
| `VIBRATION_EVENT` | новая открытка, столкновение |
| `COMPLETED_EVENT` | набрано максимальное число очков; один раз за открытие |
| `FINISH_EVENT` | финиш или выход из начатой игры; один раз |
| `SHARING_EVENT` | кнопка «Поделиться»: текст и картинка-результат (JPEG в data URL) |
| `CLOSE_EVENT` | кнопка «закрыть» или «Выйти из игры» |

## Соответствие требованиям

- **Изоляция.** Ни одного запроса за пределы папки игры: нет внешних шрифтов, библиотек, аналитики и ссылок наружу.
- **Состояние.** Хранилище страницы не используется, один вход — законченный результат.
- **Длительность.** Сессия 3–5 минут, всегда можно переиграть. Состязания на время и обратных отсчётов нет.
- **Звук.** Включается только после нажатия ребёнка, есть переключатель.
- **Экран.** Учтены безопасные зоны экрана. Кнопка «закрыть» стоит слева сверху, как в приложении. Во время
  полёта она сначала ставит паузу, чтобы случайное нажатие не закрыло игру. Правый верхний угол свободен
  под кнопку песочницы.
- **Ориентация.** Работает в портретной и горизонтальной ориентации.
- **Контент.** Персонаж — собственный кот-пилот, без персонажей Сбера и чужих брендов. Возраст 0+.
