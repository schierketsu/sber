# Котик-патриотик: полёт над Родиной

Игра для трека B «Игры» хакатона «Создаём эмоции» (Сбер × ВШЭ).

Серый котик в плаще летит над Чувашией, Коми и Бурятией. Ребёнок нажимает на экран, котик подлетает
вверх и пролетает между препятствиями. За каждые 10 очков открывается открытка о месте, над которым
он сейчас летит. Всего шесть открыток, по две на регион.

- Играть: https://schierketsu.github.io/sber/game/
- Код: https://github.com/schierketsu/sber

## Чему учит

После игры ребёнок знает шесть интересных мест трёх регионов России и может сказать, в каком регионе
каждое находится.

| Регион  | Открытки                                                                              |
| ------- | ------------------------------------------------------------------------------------- |
| Чувашия | Космическая родина (космонавт Андриян Николаев), Дерево-великан (дубу больше 420 лет) |
| Коми    | Югыд Ва, Маньпупунёр                                                                  |
| Бурятия | Озеро Байкал, Баргузинский заповедник                                                 |

Открытка появляется над тем регионом, о котором рассказывает, а фон и препятствия у каждого региона
свои: резные столбы с чувашским орнаментом, каменные столбы Коми, ледяные глыбы Байкала. Так место
связывается с регионом не только словами, но и картинкой.

## Как играть

- Нажатие в любом месте экрана — котик подлетает вверх.
- Пролетел между препятствиями — 1 очко, поймал монетку — ещё 2.
- Каждые 10 очков — открытка. Она закрывается нажатием; если ребёнок не догадался, через 5 секунд
  появляется рука-подсказка.
- После открытки идёт отсчёт 3, 2, 1, и полёт продолжается.
- На 20 и 40 очках котик перелетает в следующий регион.
- На 60 очках — финиш: все открытки можно перечитать и отправить другу картинкой с ними.
- Если котик задел препятствие, он исчезает в облачке дыма. «Попробовать ещё раз» продолжает полёт
  с последней открытки, так что собранное не пропадает.

## Как запустить

Игра — папка [game/](game/) со статическими файлами, все пути внутри относительные.

- Готовая версия: вставьте ссылку https://schierketsu.github.io/sber/game/ на стартовом экране песочницы.
- На своём сервере: скопируйте папку `game` целиком, править ничего не нужно.
- Локально: в папке `game` выполните `python -m http.server 8000` и откройте в песочнице
  `http://<IP компьютера>:8000`. Телефон и компьютер должны быть в одной сети, из эмулятора Android
  адрес компьютера — `10.0.2.2`.

| Сессия 3–5 минут, можно переиграть                  | Маршрут без ошибок занимает около 3–4 минут, «Сыграть ещё» на финише и «Начать сначала» в меню | Пройти игру                                                         |

| Без СберКота, чужих персонажей и брендов            | Свой персонаж — серый котик в плаще и маске                                                    | —                                                                   |

Случайное нажатие в угол экрана не закрывает игру: левая верхняя кнопка открывает меню, а выйти можно
только пунктом «Выйти». Правый верхний угол свободен под кнопку журнала песочницы.

## События для приложения

Игра отправляет `window.postMessage({ type, ... }, "*")`, как описано в песочницах.

| Событие           | Когда                                                                                  |
| ----------------- | -------------------------------------------------------------------------------------- |
| `VIBRATION_EVENT` | открылась открытка, котик задел препятствие                                            |
| `COMPLETED_EVENT` | набраны все очки; один раз за запуск                                                   |
| `FINISH_EVENT`    | финиш или выход из уже начатой игры; один раз                                          |
| `SHARING_EVENT`   | кнопка «Поделиться» на финише: текст и картинка с собранными открытками (PNG data URL) |
| `CLOSE_EVENT`     | пункт «Выйти» в меню                                                                   |

## Контент

Всё наполнение лежит в `content/regions.json`. Его можно поменять без правок кода, например положить
на CDN новые тексты и картинки.

| Поле                               | Что задаёт                                                         |
| ---------------------------------- | ------------------------------------------------------------------ |
| `title`, `subtitle`                | название игры, оно же на картинке «Поделиться»                     |
| `pointsPerCard`                    | через сколько очков открывается открытка (сейчас 10)               |
| `coin.chance`, `coin.value`        | вероятность монетки и сколько очков она даёт                       |
| `regions[]`                        | регионы по порядку; регион меняется после своей последней открытки |
| `regions[].name`                   | название региона, которое показывается крупно при перелёте         |
| `regions[].scene`                  | фон: `volga`, `ural` или `baikal`                                  |
| `regions[].obstacle`               | препятствия: `pillar`, `rock` или `ice`                            |
| `regions[].color`                  | цвет объёмной тени у названия региона и цифр отсчёта               |
| `regions[].speed`, `regions[].gap` | скорость и ширина просвета, то есть сложность региона              |
| `regions[].cards[]`                | открытки: `title`, `text` (абзацы через пустую строку), `image`    |

Картинка открытки — путь рядом с игрой или https-адрес CDN. Максимум очков считается сам: число
открыток × `pointsPerCard`. Если файл не загрузился или в нём ошибка, игра берёт встроенную копию
из `js/content.js` и работает дальше.

## Монетки

Монетка — не лотерея: ребёнок ничего не тратит и ничем не рискует, чтобы её получить.

- После каждого препятствия монетка появляется с вероятностью `coin.chance` = 0,35, независимо
  от предыдущих.
- Она висит между двумя препятствиями и даёт `coin.value` = 2 очка.
- За 10 препятствий в среднем появляется 3,5 монетки. Если собирать все, 60 очков набираются примерно
  за 35 препятствий вместо 60.

## Как устроен код

```
game/
  index.html              разметка экранов
  style.css               стили, безопасные зоны экрана
  content/regions.json    регионы, открытки, монетки
  img/cards/*.svg         картинки открыток
  img/hero.svg            котик по слоям: туловище, плащ, хвост, лапы, закрытые глаза
  js/bridge.js            события для приложения
  js/sound.js             звуки (Web Audio, без файлов)
  js/content.js           загрузка и проверка контента, встроенная копия на случай ошибки
  js/art.js               фоны, препятствия, котик, монетки
  js/game.js              игровой цикл, физика, экраны, «Поделиться»
```

Фоны и препятствия рисуются кодом на Canvas. Котик — векторный рисунок из нескольких слоёв: плащ и хвост
колышутся, лапы покачиваются, а при взлёте и плащ, и лапы немного отстают, как от рывка. Интерфейс
повторяет приложение СберKids: кнопки слева вверху, плашка счёта, синие окна.
